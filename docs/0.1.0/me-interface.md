# アンドロイドMEインターフェース (Android ME Interface)

ME ケーブルに直接つなげる、Singulo アンドロイド用の AE2 ノードです。**ケーブルをつないで注文先の作業指令台を 1 つ決めるだけ**で使えます。Pattern Provider・パターンの手書き登録・資材口・納品口はどれも不要で、指令台の隣に置く必要もありません。

```
 ME ケーブル ── [アンドロイドMEインターフェース]      … 同じ次元ならどこに置いてもよい
                         ┊ 作業場所カードで指定（または指令台に接して置く）
                  [作業指令台] ── レシピ棚・アンドロイド
```

レシピ: 鉄インゴット 4、AE2 エンジニアリングプロセッサ 1、ロジックプロセッサ 2、ME インターフェース 1、Singulo 資材口 1。

**パネル版**: アンドロイドMEインターフェースパネルは、AE2 のケーブルに貼る薄型版（AE2 の ME インターフェースのケーブル版と同じ扱い）です。ブロックとパネルは作業台で 1 対 1 に変換できます。働きはブロックと同じですが、ME をストレージとして見せる相手は**パネルが向いている先のブロックだけ**です（資材口に向けて貼る）。

**Singulo 0.19.0 の個別預かり API (`AndroidEscrows`) を使います。** 0.19.0 はまだ公開されていないため、現在は開発版で動作します（[開発・配布ルール](../development.md)）。

## 注文先の指令台の決め方

- **指令台に接して置く**: 置いた人が持ち主の指令台が隣にあれば、それを注文先にします。
- **作業場所カード**: 指令台を記録した Singulo の作業場所カードで、インターフェースを右クリックします（スニークなし）。同じ次元なら距離の制限はありません。
- 置いた人が所有者です。**所有者は指令台の持ち主と同じ**必要があります。
- 指令台のチャンクが読み込まれているあいだだけ発注できます（チャンクを読み込みません）。

## できること

- **レシピの共有**: 指令台にリンクしたレシピ棚の **作業台レシピ** が、そのまま AE2 のクラフト候補になります（100 tick ごとに更新）。中間素材のレシピもあれば、原料から一気に作るチェーンパターンも出します（下の「中間素材ごとにまとめて作る」）。ME 端末からその完成品を注文できます。
- **材料の隔離**: AE2 から届いた材料は、まとめたあと Singulo の**注文ごとの個別預かり**へ渡します。その材料はその注文のアンドロイドだけが使い、指令台の共有在庫や他の注文とは混ざりません。指令台の共有在庫が使われることもありません。
- **まとめ注文**: 同じ物のクラフトが続けて届くと、1 件の注文にまとめてから発注します（下の「まとめ注文」）。
- **完成品の回収**: できた物は Singulo 側の個別預かりに入り、インターフェースが**注文 ID ごとに**取り出して ME へ入れます。ME が満杯なら取り出しを止め、個別預かりに残したまま待ちます（捨てません）。
- **余った材料の返却**: 注文が終わり、担当アンドロイドが持ち物を戻すと、余り・取消分の材料も ME へ戻します。Singulo が空になったことを確認してから、その注文を片付けます。
- **ME をストレージとして使う**: インターフェースを**資材口**（または作業指令台）に接して置くと、Singulo からは ME ネットワークの中身がチェストや QIO と同じ在庫に見えます（下の「ストレージとして使う」）。

## ストレージとして使う

資材口に接したインターフェースは、ME ネットワークに入っているアイテムを、その資材口の在庫として見せます。アンドロイドは Singulo 側の注文（指令台の画面や登録した注文）でも ME から材料を取り、余りを ME へ戻します。

- **重複して数えません**: 同じ ME ネットワークのインターフェースを、同じ指令台の資材口に何台つないでも、中身を数えるのは 1 回だけです（QIO の周波数と同じ扱い）。別のネットワークは別に数えます。
- **見せる相手を限定します**: 中身が見えるのは、インターフェースの所有者が持ち主の作業指令台にリンクした資材口と、その指令台に接した面だけです。パイプ・ホッパー・他人の資材口からは空に見え、入れることもできません。
- ME ネットワークに電源・チャンネルがないときは空に見えます。
- 数えるのは ME に**入っている**物だけです（AE2 でクラフトできるだけの物は数えません）。
- 指令台に接して置いた場合、指令台の納品箱の中身も ME へ入ります。
- ストレージバスでつないだチェストが資材口にも直接接していると、そのチェストは 2 回数えられます。どちらか一方でつないでください。
- Singulo 0.19.0 の `AndroidSharedStorage` API（開発版）を使います。

## 共有されるレシピ

Singulo の個別預かりで安全に動かせる範囲だけを共有します。

| 共有される | 共有されない |
| --- | --- |
| 加工機械のレシピ（燃料・触媒なし。かまどは燃料を先に入れておけば可） | 燃料・触媒を使うレシピ（共有在庫を使うため） |
| 液体を使うレシピ（AE2 から液体として届き、注文の個別預かりで運ぶ。副産物の液体は ME へ液体で戻る） | 液体が主な完成品のレシピ、化学物質（Mekanism）を使うレシピ |
| 作業台レシピで、アイテムの材料だけを使うもの | 加工機械のレシピ・手順カードのレシピ（共有の機械を使うため） |
| 「同じ種類の別の物も使う」欄（AE2 では代替候補として表示） | 触媒・燃料を使うレシピ（共有在庫を使うため） |
| | 液体・化学物質を使う／作るレシピ、材料なしのレシピ |
| | データコンポーネント付きの完成品（名前付き・エンチャント等） |

同じ指令台に複数のインターフェースを付けると、AE2 は同じパターンの提供元が複数あるものとして扱います。

## 中間素材ごとにまとめて作る（チェーンパターン）

レシピ棚に中間素材のレシピもあると、インターフェースは、原料から完成品までを 1 回で作る**チェーンパターン**も AE2 に出します。例: 原木→板材→棒→フェンスなら「原木 5 → フェンス 12」。AE2 はこのパターンを 1 回押すだけなので、アンドロイドへの注文は 1 件になり、板材・棒・フェンスを続けて作ります。中間素材は注文の個別預かりの中だけで扱い、共有在庫には出ません。

- **原料が ME にあるときはチェーン**、原料が足りず中間素材（板材・棒）が ME にあるときは、1 工程ずつのパターンで残りを作ります。チェーンパターンは優先度の高い内部ノードから出しているので、AE2 は必ずチェーンを先に試します。原料と中間素材の両方があるときは、原料から作ります。
- 画面の「最近」の行に、AE2 から届いたクラフトが「一括」（原料から一括）か「1工程」かで出ます。
- 原料の数は割り切れるように倍数をとるので（最大 64 倍）、AE2 が送る原料とアンドロイドが使う量が一致します。割り切れない場合は 1 回分ずつ切り上げ、余りは注文の終わりに ME へ返します。
- 「同じ種類の別の物も使う」欄は原料として扱います（その先は展開しません）。展開は 8 段まで、循環するレシピ（インゴット↔ブロックなど）は展開しません。

## まとめ注文

AE2 はクラフト 1 回分（1 バッチ）ずつ材料を送ってきます。インターフェースは次の規則で注文をまとめます。

1. 届いた材料はインターフェース内に保持し（最大 256 スタック）、同じ完成品の「まとめ中」の注文に数を足します。まとめ中の材料はどの面からも取り出せません。
2. 最後の投入から 10 tick 何も来ない、最初の投入から 100 tick たつ、4096 個または 128 スタックに達する、のいずれかで Singulo に渡します。
3. Singulo が受け付けた時点で材料の持ち主が Singulo の個別預かりに移ります。断られた場合（空いているアンドロイドがいない、預かり枠が満杯など）は材料を保持したまま 5 秒ごとに再試行します。一度受け付けられた注文で材料を二重に渡すことはありません。

**個別預かりの注文は 1 件につきアンドロイド 1 体が専任で担当します。** まとめることで、同時に必要なアンドロイドの数を抑えられます。

## 画面（素手で右クリック）

AE2 の ME インターフェースと同じ作り（明るい灰色の画面・スロットの列・下にプレイヤーのインベントリ）の専用画面が開きます（所有者・OP のみ）。

| 場所 | 表示 |
| --- | --- |
| 上の文字 | ME 接続（オンライン／チャンネルなし／オフライン）と優先度、注文先の作業指令台。問題があるときだけ赤字で 1 行。カーソルを合わせると共有レシピの数・注文数・預かり量・最近 AE2 から届いたクラフト |
| 注文の列 | 注文ごとに完成品のアイコンと数。下端の色が状態（橙: まとめ中、黄: 発注待ち、青: 製作中、緑: 完了、赤: 取消・失敗）。カーソルを合わせると状態・ME へ戻った数・理由 |
| ME 返却待ちの列 | ME に入れる前の完成品・返却材料。**プレイヤーもアイテムを入れられ**（Shift + クリック可）、入れた物は ME へ送られます。取り出しはできません（AE2 のジョブが待っている完成品のため） |

- **優先度**（右上のレンチ）: AE2 標準の優先度画面です。このインターフェースが出すパターンの優先度で、同じ物を作れるパターンが複数あるとき、AE2 は優先度の高い方を先に使います。チェーンパターンは常にこの値 +1 で出します。
- **全取消**（右下、Shift + クリック）: まとめ中・製作中の注文をすべて取り消します。材料は ME へ戻ります。AE2 側のジョブは端末からキャンセルしてください。
- チャット欄への表示はなくなりました。コマンドで確認したいときは `/appliedsingulo interface <x y z> status|cancel`（パネルの場合はケーブルの座標）。
- 壊すと、まとめ中の材料と返却待ちの物はその場に落ちます。Singulo に渡し済みの注文は取り消され、担当アンドロイドが戻ったあとに完成品・材料が**壊した場所に**落ちます（その場所が読み込まれているとき）。

## 制約

- AE2 側のジョブは、Singulo の注文が取消・失敗になっても自動では止まりません。端末からキャンセルしてください。
- 個別預かりは次元ごとに最大 64 件、1 件 128 スタックまでです（Singulo 側の制限）。
- Minecraft は Singulo の預かりデータと AE2・インターフェースのデータを別々に保存します。保存の途中でサーバーが異常終了した場合の完全な整合性は保証されません（Singulo 側の仕様）。

## 在庫維持

画面の「在庫維持」の列に、ME に置いておきたい物と数を 9 つまで設定できます。ME の在庫がその数を下回ると、インターフェースが AE2 のクラフトジョブを出し（足りない材料があれば作れる分だけ）、アンドロイドが作ります。**AE2 のクラフト CPU が必要**です。

- アイテムを持ってスロットをクリック: その物を設定（数は持っている数）
- 素手で右クリック: 解除　／　ホイール: ±1（Shift で ±64）
- スロットの下端の色: 緑 = 足りている、青 = 製作中、赤 = 材料不足・パターンなし・CPU なし（カーソルで理由）

## 状態エミッターと注文モニター

- **アンドロイド状態エミッター**（ケーブル部品。レシピ: AE2 レベルエミッター + ロジックプロセッサ + Singulo 遺構の照明）: 同じ ME ネットワークのアンドロイドMEインターフェース全体の状態で、レッドストーン信号を出します。右クリックで条件を切り替え: 「注文が止まっている」（拒否・ME 満杯・指令台未設定）→「注文がある」→「注文がない」。
- **アンドロイド注文モニター**（ケーブル部品。レシピ: AE2 ストレージモニター + ロジックプロセッサ + Singulo 机のモニター）: AE2 のストレージモニターのように、今の注文の完成品・ME へ戻った数・製作中/まとめ中の件数を表示します。止まっている注文があると赤字になります。
