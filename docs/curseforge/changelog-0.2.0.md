# Applied Singulo 0.2.0 Beta

- Android ME Interfaces can offer AE2 crafting patterns with a fluid ingredient when the linked Android workshop recipe supports a bucket-to-fluid substitution. Ordinary bucket patterns remain available.
- Each order keeps its materials and returns separate from other orders. The output is an item; recipes with a primary fluid output and general machine processing are not supported by this feature.
- Requires Minecraft 1.21.1, NeoForge 21.1.256+, and Singulo 0.21.0 or later in the 0.21 series.
