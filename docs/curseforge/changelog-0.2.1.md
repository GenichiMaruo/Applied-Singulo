# Applied Singulo 0.2.1 Beta

- Adds compatibility with Singulo 0.22.0. Existing AE2 patterns that use fluid ingredients for supported Android workshop recipes continue to produce item outputs.
- Requires Minecraft 26.1.2, NeoForge 26.1.2.126+, and Singulo 0.21.x or 0.22.x.
